# Stage 05 – Outreach Preparation

## Inputs

- Layer 3: `../../_config/voice.md`
- Layer 3: `../../shared/email_templates/value_first.md`
- Layer 3: `../../shared/demo_brief.md`
- Layer 4: `../04_enrich/output/` (enriched records)

## Process

For each prospect the human wants to contact:

1. Draft a personalized value-first email (subject + body) following the voice rules and template structure.
2. Optionally produce a short "demo concept" or observation note the human can use or turn into a visual.
3. Suggest the best channel and any timing notes.

Keep everything reviewable. The human will edit before sending.

## Outputs

- `outreach_drafts.md` (or one file per prospect) → `output/`
- Any demo concepts → `output/demo_concepts/`
