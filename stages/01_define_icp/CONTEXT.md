# Stage 01 – Define / Refine ICP

## Inputs

- Layer 3: `../../_config/icp.md`
- Layer 3: `../../_config/services.md`
- Layer 3: `../../_config/sources.md`
- Layer 4 (if exists): current campaign `CONTEXT.md` and any previous ICP notes
- Human conversation / questionnaire answers

## Process

Work with the human to produce a clear, campaign-specific Ideal Customer Profile.

Output should answer:
- Who exactly are we looking for in *this* campaign?
- What concrete signals indicate a good prospect?
- What are the disqualifiers?
- Which sources will we prioritize?
- Any scoring weight adjustments for this campaign?

Write the refined ICP so later stages can treat it as the source of truth for this campaign.

## Outputs

- `icp.md` → `output/` (the living ICP for this campaign)
- Optionally update the campaign’s root `CONTEXT.md` with a summary
