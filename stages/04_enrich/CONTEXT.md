# Stage 04 – Enrich

## Inputs

- Layer 4: `../03_qualify/output/shortlist.md`
- Campaign ICP and any existing prospect notes

## Process

For each shortlisted prospect, gather the information needed for high-quality, personalized outreach:

- Confirm / find best contact path (email, form, phone, LinkedIn if relevant)
- Deeper website audit notes (specific UX / conversion / mobile / clarity issues)
- Review themes that can be referenced positively
- Any recent signals (new location, hiring, awards, etc.)
- Suggested personalization angles

Write one enriched record per prospect (or a rich table). These records become the foundation for stage 05.

## Outputs

- Individual files or a rich `enriched_shortlist.md` → `output/`
- Copy or link key records into the campaign’s `knowledge/prospects/` for the permanent knowledge base
