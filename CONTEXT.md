# CONTEXT.md – Layer 1 (Workspace Routing)

## Purpose

A reusable, expandable prospecting system focused on **Digital Opportunity**: businesses that already have demand and reputation but whose digital presence underperforms relative to that opportunity.

Primary product angle: focused landing pages that turn existing attention (Google, social, reviews) into clearer conversion paths (call, quote, booking, WhatsApp).

## How to orient

1. Read `AGENT.md`.
2. Read `campaigns/_index.md` to see active and archived campaigns.
3. For the active campaign, read its `CONTEXT.md` and `status.md`.
4. Stage contracts live in `stages/*/CONTEXT.md`.
5. Global durable knowledge lives in `_config/` and `shared/`.

## Multi-campaign model

Every distinct experiment / ICP / geography / niche set gets its own folder under `campaigns/`.

The global system is reusable. Campaign instances stay focused and measurable.

## Conceptual pipeline

```
(Optional) Market / Niche Discovery
        ↓
ICP Definition
        ↓
Sourcing (demand + reputation first)
        ↓
Qualification (multi-dimensional + evidence)
        ↓
Enrichment (digital gap, social, reviews, contacts)
        ↓
Outreach prep
        ↓
Pipeline
```

## Digital Presence spectrum (not binary)

- Excellent website + conversion system
- Good website
- Basic website
- Outdated / weak website
- Social-media-only presence
- Google-profile-only presence
- Virtually no meaningful digital presence

“No website” is one form of digital weakness, not the only one.
