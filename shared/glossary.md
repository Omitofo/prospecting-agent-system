# Glossary

- **ICP** – Ideal Customer Profile
- **Campaign** – One self-contained prospecting effort for a specific niche / ICP / time window
- **Layer 0–4** – ICM context layers (see original ICM paper)
- **Stage contract** – The Inputs / Process / Outputs section inside each `stages/*/CONTEXT.md`
- **Shortlist** – Prospects that passed the scoring threshold and are ready for enrichment / outreach
- **Value-first** – Outreach style that leads with observation + useful insight, never hard sell
